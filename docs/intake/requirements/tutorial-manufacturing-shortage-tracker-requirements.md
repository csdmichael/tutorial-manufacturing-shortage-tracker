# Requirements

Manufacturing teams need a quick way to understand which shortages could affect production schedules. Finding the root cause usually requires coordination across multiple departments.

Build a working tutorial application for Manufacturing Shortage Tracker. It should let users complete the main workflow from start to finish, review and update the information they need, and receive clear feedback for successful and unsuccessful actions. Use realistic sample data, validate user input, protect sensitive information, work on desktop and mobile screens, and include automated tests for the main workflow.
